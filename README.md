## 🚀 Step-by-Step GitHub Pages Deployment

To host this website on your free `github.com/mohamedOmar11111/mohamed-omar-portfolio` repository:

### Option A: Via Command Line (Recommended)

1. Open your terminal and navigate to this folder:
   ```bash
   cd /Users/o-elkhazragy/Desktop/Growth_Architect_HQ/02_Active_Clients/The_Growth_Architect/website
   ```

2. Initialize a new git repository:
   ```bash
   git init
   ```

3. Add all files to the staging area:
   ```bash
   git add .
   ```

4. Commit the codebase:
   ```bash
   git commit -m "feat: deploy Growth Architect Sovereign Portfolio v7.0"
   ```

5. Create a main branch:
   ```bash
   git branch -M main
   ```

6. Link it to your public GitHub repository:
   ```bash
   git remote add origin https://github.com/mohamedOmar11111/mohamed-omar-portfolio.git
   ```
   *(Note: Make sure this repository exists on your GitHub account).*

7. Push the files:
   ```bash
   git push -u origin main --force
   ```

8. Go to your repository settings on GitHub -> **Pages** -> Under **Build and deployment**, select **Deploy from a branch** and set it to **main / (root)**. Click Save.

### Option B: Drag and Drop (No Command Line)

1. Open [GitHub](https://github.com/) in your browser.
2. Go to your repository: `mohamed-omar-portfolio`.
3. Open Finder, go to: `/Users/o-elkhazragy/Desktop/Growth_Architect_HQ/02_Active_Clients/The_Growth_Architect/website`
4. Drag and drop all files (`index.html`, `index.css`, `llms.txt`, and the `assets` folder) directly into your repository window on the web browser.
5. Click **Commit changes** at the bottom of the page.
